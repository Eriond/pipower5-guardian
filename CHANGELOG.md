# Changelog

## 1.0.0 — 2026-11-20

First public release of the commissioned direct-I²C Home Assistant integration.

- Mandatory graceful host shutdown, power and battery notifications, and 18 entities.
- Shared notification script supports multiple recipients.
- Bounded background polling, I²C timeout handling and shutdown retry protection.
- Correct one-shot listener cleanup during shutdown.
- Local SunFounder integration icon and logo.
- Installation guide, protocol provenance and 35 regression tests.
